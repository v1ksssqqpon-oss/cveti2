# ДаЦветы — сайт-витрина (Краснодар)

Чистый HTML + CSS + JS, без фреймворков. Все файлы в одной папке.

## Файлы
- `index.html` — витрина (главная)
- `admin.html` — панель управления (вход по паролю)
- `styles.css` — оформление (тёмная тема, терракот)
- `store.js` — данные букетов + категории (localStorage)
- `app.js` — логика витрины (папки, модалка, формы)
- `admin.js` — логика админки (добавить / скрыть / удалить)

## Фотографии
Положите рядом с `index.html` (в эту же папку):
- `hero.jpg` — фон баннера (горизонтальное фото, можно фасад студии)
- `bouquet-1.jpg` … `bouquet-6.jpg` — фото букетов

Пока файлов нет — показывается терракотовая заглушка, ничего не ломается.
Новые фото можно загружать прямо в админке (сохраняются в браузере).

## Админка

2. Пароль по умолчанию: **dacvety2026** — поменяйте в `store.js` (`ADMIN_PASS`).
