# Фотографии для сайта «ДаЦветы»

Положите сюда свои фото с **точно такими именами файлов**. Пока файла нет —
на сайте показывается красивый заглушка-блок терракотового цвета, так что
ничего не «ломается».

## Первый экран (баннер-витрина)
- `storefront.jpg` — фон баннера: **горизонтальное** фото (можно ваш ночной фасад
  студии). Сверху ляжет тёмное затемнение, поэтому текст всегда читается.

## Витрина (карточки букетов)
- `bouquet-1.jpg` — Нежность (4 990 ₽)
- `bouquet-2.jpg` — Терракота (5 490 ₽)
- `bouquet-3.jpg` — Магия пионов (6 990 ₽)
- `bouquet-4.jpg` — Белое облако (4 490 ₽)
- `bouquet-5.jpg` — Для любимых (7 490 ₽)
- `bouquet-6.jpg` — Королевский (9 990 ₽)
- `bouquet-7.jpg` — Алый закат (5 990 ₽)
- `bouquet-8.jpg` — Коралловый риф (8 490 ₽)

## Галерея
- `gallery-1.jpg` … `gallery-8.jpg` — любые красивые фото букетов
  (разной высоты — так masonry-сетка смотрится живее)

## Рекомендации
- Формат: **JPG** или **WEBP**, ширина 1200–1600 px.
- Каталог и hero лучше снимать **вертикально** (портрет).
- Вес одного файла желательно до 300–400 КБ (сожмите на squoosh.app).

## Подсказка по вашим загруженным фото
Из присланных снимков удачно лягут так:
- Коралловые пионы + кремовая гербера → `bouquet-2.jpg` (Терракота)
- Розовые пионы с жемчугом → `bouquet-1.jpg` (Нежность) или `hero.jpg`
- Красные розы + эустома + эвкалипт → `bouquet-5.jpg` (Для любимых)
- Плотный коралловый букет пионов → `bouquet-6.jpg` (Королевский)
- Бело-розовые пионы с синей нигеллой → `bouquet-4.jpg` (Белое облако)
